# 하역 셀 사양서 (v1.0)

> 작성: 2026-10-10 / 기준: 작업 요구서((가상) 이천 택배 물류센터, 혼합 상자 로봇 하역 셀)
> 용도: Phase 2 디지털트윈 구축 시 그대로 가져다 쓰는 숫자. 바뀌면 이 문서를 먼저 고친다.
> 환경: Isaac Sim 6.0.1, ROS 2 Jazzy, MoveIt 2

## 1. 셀 구성

| 구성 | 사양 | 근거 |
|---|---|---|
| 팔레트 | KS T11, 1100×1100×150mm, 1개 | 국내 물류 표준 팔레트 |
| 적재 | 혼합 상자, 팔레트 윗면에서 최대 1.2m (바닥 기준 1.35m) | 도달 범위 계산 (4장) |
| 로봇팔 | **Universal Robots UR20** (도달 1750mm, 가반 20kg) | UR10(1300mm)은 먼 모서리에 닿지 않음 |
| 받침대 | 높이 0.7m, 팔레트 앞 가장자리에서 0.25m | 최상단·최하단 모두 도달 |
| 그리퍼 | 흡착 패드 150×150mm, 툴 길이 0.2m, Isaac Sim Surface Gripper | 최소 상자 윗면(220×190)보다 작게 |
| 카메라 | 팔레트 중심 위, 바닥에서 3.0m, 수직 하향, 1280x720 pinhole | 시야·해상도 계산 (5장) |
| 컨베이어 | 높이 0.75m, 폭 0.6m, 로봇 왼쪽 0.8m 지점에서 시작 | 일반 컨베이어 높이 |

### 배치 좌표 (단위 m, 팔레트 중심 바닥 = 원점, +y = 로봇에서 팔레트 쪽)

| 물체 | 위치 | 비고 |
|---|---|---|
| 팔레트 중심 | (0, 0, 0) | 윗면 z = 0.15 |
| 로봇 베이스 | (0, −0.80, 0.70) | 받침대 위, 팔레트 앞 가장자리(y = −0.55)에서 0.25m |
| 컨베이어 시작점 | (−0.80, −0.80, 0.75) | −x 방향으로 진행 |
| 카메라 | (0, 0, 3.0) | 수직 하향 |

## 2. 상자

| 호수 | 가로×세로×높이(mm) | 비고 |
|---|---|---|
| 1호 | 220×190×90 | 최소 크기 |
| 2호 | 270×180×150 | |
| 3호 | 340×250×210 | 시판 제품 규격으로 확인 |
| 4호 | 410×310×280 | |
| 5호 | 480×380×340 | 시판 제품 규격으로 확인 |
| 6호 | 520×480×400 | 최대 크기 |

- 1·2·4·6호는 일반적으로 알려진 우체국 규격값, 실측으로 확인 예정
- 시뮬레이션 랜덤화 범위: 위 규격 ±10%
- 질량: 0.5~10kg (UR20 가반 20kg − 그리퍼 약 3kg 여유)
- 외관 변수: 골판지 색 3~5종, 테이프(투명·갈색·인쇄), 송장 라벨 위치, 찌그러짐, 비닐 랩
- 윗면은 별도 prim + 시맨틱 라벨 `top_face`
- 한 팔레트 상자 수: 10~40개, 층수 2~6

## 3. 로봇팔·그리퍼

| 후보 | 도달 | 가반 | 판정 |
|---|---|---|---|
| UR10 / UR10e | 1300mm | 10 / 12.5kg | 탈락. 먼 모서리 최하단까지 1.50m 필요 |
| **UR20** | **1750mm** | **20kg** | **선정.** 최악 지점 1.65m (도달의 94%) |
| KUKA KR210 등 산업용 | 2700mm 급 | 210kg 급 | 과잉. 셀이 커지고 협동로봇 아님 |

- Isaac Sim 6.0.1 에셋: `Isaac/Robots/UniversalRobots/ur20/ur20.usd` (재질·모양 정상 확인)
- 링크 이름 `base_link` ~ `wrist_3_link`가 ROS `ur_description`과 같은 체계
- ROS 2 Jazzy: `ros-jazzy-ur-description` 3.5.1(UR20 포함), `ros-jazzy-ur-moveit-config` 3.9.0
- 흡착: UR20 툴 플랜지에 패드 바디 + D6 조인트 attachment point (Isaac Sim 공식 UR10 흡착 예제 방식). Max Grip Distance 0.01m에서 시작, 힘 한계는 10kg 상자로 시험해 결정

## 4. 도달 범위 검증 (계산)

가정: UR20 어깨 높이 = 받침대 + 0.24m, 상자 윗면 위 손목 높이 여유 0.35m

| 지점 | 필요 거리 | UR20 대비 |
|---|---|---|
| 먼 모서리 · 최하단 | 1.50m | 86% |
| 먼 모서리 · 최상단 (1.2m 적재) | **1.65m** | **94% (최악)** |
| 가까운 중앙 · 최상단 | 0.80m | 46% |

- 받침대 0.5m·간격 0.35m면 최악 지점 1.83m → 도달 불가. 그래서 받침대 0.7m, 간격 0.25m
- Phase 2에서 실제 IK로 재검증, 안 되면 적재 최대 높이 1.0m로 (최악 1.56m, 89%)

## 5. 카메라

| 항목 | 값 |
|---|---|
| 위치 | 팔레트 중심 위, 바닥에서 3.0m |
| 모델 | `opencvPinhole`, 왜곡 없음 (렌즈 왜곡은 Phase 3 랜덤화) |
| 해상도 | 1280x720 (Cosmos 입력과 동일) |
| 화각 | 수직 43°, 수평 70° |
| 픽셀 해상도 | 1.8mm/px (최상단) ~ 3.1mm/px (팔레트 바닥) |
| 최소 상자 윗면 | 1호 220×190mm → 약 70×60px 이상 |

- 촬영 시점: 로봇팔이 시야 밖으로 물러난 뒤 촬영 → 인식 → 집기
- 깊이: 같은 위치의 depth 출력으로 집을 높이 계산

## 6. 하역 동작 순서

1. 로봇 대기 자세 (카메라 시야 밖)
2. 촬영 → 인식 모델이 `top_face` 마스크 출력
3. 깊이로 가장 높은 상자 선택 → 윗면 중심·높이로 흡착 지점 계산
4. MoveIt 2로 흡착 지점 위 0.1m 접근 → 하강 → 흡착 → 상승
5. 컨베이어 위로 이동 → 놓기 → 대기 자세로 복귀
6. 팔레트가 빌 때까지 반복
